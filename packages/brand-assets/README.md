# BorlaAlert GH Brand Assets

This directory contains official vector marks, emblems, and visual assets for the BorlaAlert GH Civic Cleantech Platform.

## Assets Directory

- **`logo.svg`**: The primary vector emblem for BorlaAlert GH.
  - Geometry: 120x120px rounded squircle (`#16A34A` Emerald Green)
  - Radar ring: Dotted radial pulse (`#DCFCE7`)
  - Waste Bin glyph: Precision-balanced eco-bin with dynamic collection lines
  - Alert indicator: Amber notification badge (`#F59E0B`)
- **`logo-preview.png`**: High-resolution raster preview of the emblem.
